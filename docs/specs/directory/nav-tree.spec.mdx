# Navigation Tree

This specification describes the navigation tree functionality of IMDirectory.

* Open IMDirectory

## Expand nodes
* Expand tree node "Ontologies"
* Tree contains "SNOMED CT Concept (SNOMED RT+CTV3)"

## Load more
* Expand tree node "Ontologies"
* Expand tree node "SNOMED CT Concept (SNOMED RT+CTV3)"
* Expand tree node "Clinical finding (finding)"
* "Clinical finding (finding)" has at most "51" children
* Scroll down tree
* Click tree node "Load more..."
* Scroll up tree
* "Clinical finding (finding)" has at least "52" children

## Select node and route
* Click tree node "Ontologies"
* Directory table contains "Ontologies"

## Shows overlay on hover
* Hover over tree node "Ontologies"
* Overlay panel contains "Ontologies"
