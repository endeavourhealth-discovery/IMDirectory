# Viewer - Set

This specification describes the set (value set) viewer functionality in IMDirectory

* Open IMDirectory
* Login
* Open filters
* Select concept type "Data model bound value set"
* Close filters
* Search for "Autism Spectrum Disorders (Data model value set)"
* Select "Autism Spectrum Disorders (Data model value set)" result

## Set tab opens
* Concept title displays "Autism Spectrum Disorders (Data model value set)"
* Set tab is active

## Download set
* Click set download button
* Select download format "csv"
* Click download confirmation
