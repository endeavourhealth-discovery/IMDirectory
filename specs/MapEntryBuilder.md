# Map Entry builder

## Functional Requirements

To set the type of Map and edit a list of Map entries.
Editing consists of

1. Adding a new Map entry
2. Removing an existing Map entry
3. Editing the fields of the map entry
4. Clear the list.
5. Upload a tab or csv file of entries from a local source.
6. Save the list of entries.
7. Cancel any changes

The fields that are completed are determined by the typ of Map. One of the following

1. "Direct map" which requires a source entity and a target text and target value
2. "Range Map" which requires a source entity, source type, source property, range from and range to and a taget text
   and target value
3. "Exact Value Map," which requires a source entity, source type, source property and a value, which may text or
   numeric, and a target text and taget value
   numeric.

The source Text is mutually exclusive to source Value and to (rangeFrom and Range to fields)

## User interface requirements

Can only be edited once the type of map has been selected

1. Resides in the right-hand column of a splitter as generated by the Form editor
3. Row column approach i.e. one or two rows per map entry and a column for each field
4. The fields are determined by the map type as described below.
5. Use the entity selector for the source entity, source type and source property fields.
4. Button for upload from a file.
5. Buttons for delete on each row

Note that the save or cancel buttons are in the editor or creator thus all entries are work in progress.

## Technical approach

### Shape component

The map Entry builder is a shape component residing in the ShapeComponents directory and used by the Form generator.

the form generator derives its fields from the relevant shape component.ts file which is a json model of the form

In this case the file is src/constants/editorShapes/SemanticMap.ts

The form editor populates and provides an editorEntity which can be used in the components

IM is the namespace for the predicates that start with http://endhealth.info/im#

The map type is populated in the editorEntity[IM.MAP_TYPE] predicate as is a TTIRef in a previous component

Map types are one of the following:

1. Direct Map : http://endhealth.info/im#DirectMap
2. Range value Map http://endhealth.info/im#RangeMap
3. Exact value map http://endhealth.info/im#ExactValueMap

The map entry builder must use the map type to determine the fields to display.

The component is called from the VerticalLayout. vue component that passes in the value of the entity predicate
IM.MAP_ENTRY which is a list of Objects that have the following predicates

A Map entry has the following predicates with the following tokens

1. IM.SOURCE_ENTITY  (equivalent to "http://endhealth.info/im#sourceEntity")
2. IM.SOURCE_TYPE (equivalent to "http://endhealth.info/im#sourceType")
3. IM.SOURCE_PROPERTY (equivalent to "http://endhealth.info/im#sourceProperty")
4. IM.RANGE_FROM (equivalent to "http://endhealth.info/im#rangeFrom")
5. IM.RANGE_TO (equivalent to "http://endhealth.info/im#rangeTo")
6. IM.SOURCE_TEXT (equivalent to "http://endhealth.info/im#sourceText")
7. IM.SOURCE_VALUE (equivalent to "http://endhealth.info/im#sourceValue")
8. IM.TARGET_TEXT (equivalent to "http://endhealth.info/im#targetText")
9. IM.TARGET_VALUE (equivalent to "http://endhealth.info/im#targetValue")

The relationship between map type and map entry fields is as follows:

(not tha IM is short for http://endhealth.info/im#)

| Map type          | Source entity | Source type | Source property | Range from | Range to | Source text | Source value | Target text | Target value |
|-------------------|---------------|-------------|-----------------|------------|----------|-------------|--------------|-------------|--------------|
| IM.DirectMap      | Yes           | No          | No              | No         | No       | Yes         | No           | Yes         | Yes          |
| IM.RangeValueMap  | Yes           | Yes         | Yes             | Yes        | Yes      | No          | No           | Yes         | Yes          |
| IM.ExactvValueMap | Yes           | Yes         | Yes             | No         | No       | optional    | optional     | Yes         | Yes          |

Source entity, source type and source property fields are TTIRefs, that is have iri field and name field.

target text is a single word text designed to be used as enum when passed as variable to a method
target value is an integer value that may alternatively be used as an enum when passed as a variable to a method.

## Sub components used in data entry

Use Primevuew numeric input for fromValue and toValue and source value

Use Primevue text input for source text

The entity selector is: /components/shared/AutompleteSearchBar for source entity,source type and source property as
this component is used to find entities. This returns a SearchResultSummary which can be used to create a TTIRef.
