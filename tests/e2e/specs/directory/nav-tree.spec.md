# Navigation Tree

This specification describes the navigation tree functionality of IMDirectory.

* Open IMDirectory

## Expand nodes
* Expand tree node "Ontologies"
* Tree contains "SNOMED CT Concept (SNOMED RT+CTV3)"

## Load more
* Expand tree node "Ontologies"
* Expand tree node "SNOMED CT Concept (SNOMED RT+CTV3)"
* Expand tree node "Clinical finding (finding)"
* "Clinical finding (finding)" has at most "51" children
* Scroll "Load more..." into view
* Load more children of "Clinical finding (finding)"
* Scroll up tree
* "Clinical finding (finding)" has at least "52" children

## Select node and route
* Click tree node "Ontologies"
* Directory table contains "Ontologies"

## Shows overlay on hover
* Hover over tree node "Ontologies"
* Overlay panel contains "Ontologies"

## Adds favourites
* Login
* Search for "Scoliosis deformity of spine (disorder)"
* Select "Scoliosis deformity of spine (disorder)" result
* Click favourite button
* Click logo to return to homepage
* Expand tree node "Favourites"
* Parent "Favourites" has child "Scoliosis deformity of spine (disorder)"

## Removed from tree
* Login
* Search for "Scoliosis deformity of spine (disorder)"
* Select "Scoliosis deformity of spine (disorder)" result
* Click favourite button
* Click logo to return to homepage
* Expand tree node "Favourites"
* Tree contains "Scoliosis deformity of spine (disorder)"
* Click "Clear favourites" button
* Click dialog confirm
* Parent "Favourites" has no children
