# Viewer - Concept

This specification describes the concept viewer functionality in IMDirectory

* Open IMDirectory
* Login
* Search for "atshma discorder"
* Select "Asthma (disorder)" result

## Concept loads
* Concept title displays "Asthma (disorder)"

## Find in tree
* Click find in tree button
* Hierarchy tree contains "Asthma (disorder)"

## Download concept
* Click download button
* Confirm download dialog

## Favourite concept
* Click favourite button
* Tree node "Favourites" has children

## Breadcrumb shows route
* Breadcrumb contains "Disorder of respiratory system (disorder)"
* Breadcrumb contains "..."
* Breadcrumb contains "Health Information Model"

## Expand breadcrumb ellipsis
* Click breadcrumb ellipsis
* Breadcrumb overlay menu has items

## Navigate from breadcrumb
* Click breadcrumb term "Disorder of respiratory system (disorder)"
* Concept title displays "Disorder of respiratory system (disorder)"

## Navigate from breadcrumb ellipsis menu
* Click breadcrumb ellipsis
* Click breadcrumb menu item "Ontologies"
* Concept title displays "Ontologies"

## Details tab shows details
* Details container has tree nodes

## Expand all details nodes
* Click expand details button
* Details container has expanded nodes

## Collapse all details nodes
* Click collapse details button
* Details container has no expanded nodes

## Terms tab
* Click tab "Terms"
* Terms table has rows

## Maps tab shows mappings
* Click tab "Maps"
* Has map table "hasMap"
* Has map table "matchedFrom"
* Maps are in priority order

## Contents tab
* Click tab "Contents"
* Contents table has rows

## Used In tab
* Click tab "Used In"
* Used in table has rows

## Hierarchy Position tab
* Click tab "Hierarchy Position"
* Current node is selected "Asthma (disorder)"

## Load more in hierarchy
* Click tab "Hierarchy Position"
* Hierarchy tree has "22" nodes
* Click load more in hierarchy
* Hierarchy tree has more than "22" nodes

## Climb hierarchy
* Click tab "Hierarchy Position"
* Click parent button
* Parent hierarchy changed

## Hierarchy routes on click
* Click tab "Hierarchy Position"
* Click hierarchy node "Allergic asthma"
* Concept title displays "Allergic asthma"

## Entity Chart tab
* Click tab "Entity Chart"
* Entity chart has "isA" rows
* Entity chart has "subtype" rows

## Entity Chart routes on click
* Click tab "Entity Chart"
* Click subtype row "Allergic asthma"
* Concept title displays "Allergic asthma"

## Graph tab
* Click tab "Graph"
* Graph container contains "Asthma (disorder)"

## JSON tab
